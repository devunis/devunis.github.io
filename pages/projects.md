## 공개 프로젝트

## 🛍 SenPick
- **개요**: GPT-4o + RAG(Qdrant)로 취향·상황 기반 개인화 추천  
- **역할**: 아키텍처 설계, 백엔드, 에이전트 오케스트레이션(LangGraph)
- **기능**: 대화 기반 선물 추천, 추천 이유 제공, 상품 비교
- **스택**: GPT-4o · LangGraph · Qdrant · RAG · Django
- **링크**: [GitHub](https://github.com/devunis/SenPick)  

---

## 🧳 Travel Checker
- **개요**: Django + Gemma3 + FAISS RAG로 국가별 반입금지 품목 안내  
- **역할**: LLM 백엔드, 데이터 전처리/크롤링, API 설계, 파인튜닝(PEFT/QLoRA)  
- **성과**: **10개국 반입금지 물품 데이터 수집 및 파인튜닝 진행**  
- **스택**: Django · Gemma3 · FAISS · 공공데이터 API · RAG  
- **링크**: [GitHub](https://github.com/devunis/Travel-Checker)

## 🎤 Tongue Twist
- **개요**: Streamlit + OpenAI Whisper/GPT-4o 기반 한국어 발음 연습 게임  
- **역할**: 풀스택 개발, AI 파이프라인 구축 (STT → LLM → TTS)
- **성과**: **실시간 음성 인식 및 피드백 시스템 구현**, 인터랙티브 UI/UX 설계  
- **스택**: Streamlit · OpenAI Whisper · GPT-4o-mini · TTS · Python  
- **링크**: [GitHub](https://github.com/devunis/tongue-twist)
